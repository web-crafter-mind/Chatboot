# 🤖 Chatboot AI

A modern AI chatbot built with **React, TypeScript, Vite, and Tailwind CSS**.  
Chatboot AI provides a clean ChatGPT-like interface with conversation history, dark mode, streaming AI responses, and user profile support.

## ✨ Features

- 💬 AI-powered chat
- ⚡ Streaming responses
- 📂 Conversation history
- 📌 Pin conversations
- 🗂 Archive conversations
- ✏️ Rename conversations
- 🗑 Delete conversations
- 👤 User profile setup
- 🌙 Dark & Light mode
- 📱 Responsive design
- 🎨 Modern UI with Tailwind CSS

## 🛠 Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Puter AI

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/web-crafter-mind/Chatboot.git
```

Go into the project

```bash
cd Chatboot
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
